# AIsChat 启动器安装程序

## 下载

前往 [Releases](https://github.com/Coprexist/AIsChat-Releases/releases) 页面下载最新版本。

## 安装

1. 下载 AIsChat-Installer.exe2. 双击运行安装程序3. 选择安装语言（简体中文 / English）4. 选择安装目录（默认 %LOCALAPPDATA%\AIsChat）5. 完成安装

## 卸载

- 开始菜单 → AIsChat → 卸载 AIsChat- 或控制面板 → 程序和功能 → AIsChat 启动器 → 卸载
